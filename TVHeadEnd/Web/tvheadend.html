Each channel is probed with ffprobe when it starts, so Jellyfin learns which subtitle and audio tracks it carries. That probe is a second TVHeadend subscription and a few seconds of analysis before playback begins, which on a single tuner can slow channel switching or contend for the adapter.
Only has an effect together with the setting above: a probe of a running broadcast often reports interlaced video as progressive, which stops Jellyfin from deinterlacing it. Without probing, live TV and recordings are already reported as interlaced.
